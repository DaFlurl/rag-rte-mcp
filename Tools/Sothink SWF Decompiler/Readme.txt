DESCRIPTION

        Leading Flash decompiler and Flash to html5 
        converter. Converts SWF to FLA, FLEX or HTML5. 
        Easily extract Flash resources like shape, image, 
        sound (mp3, wav), video (flv), text, sprite, 
        ActionScript, etc; Edits shape elements in SWF; 
        Replaces image/text/sound for SWF; Supports Flash 
        CS3/CS4/CS5/CS6 and ActionScript 2.0/3.0; Able to get 
        XFL file from SWF; Globally searches all 
        ActionScript; Exports SWF resources in batch; 
        One-click online Flash capture and download.

MAIN FEATURES

        * Convert SWF to FLA, SWF to FLEX, SWF to HTML5 
          and get XFL from Flash.
        * Extract SWF elements. 
        * Edit shape elements in SWF.
        * Replace image/ text/ sound elements for SWF. 
        * Extract SWF from Flash EXE.
        * Download online Flash with one-click.
        * Support Flash CS3/CS4/CS5/CS6.
        * Support ActionScript2.0/3.0.
        * Decompile SWF in batch mode.
        * Globally search all ActionScript.
        * Export FLV video from Flash.
        * Auto-recognize system language.
