# RoboEvony Project Documentation
Version: 11.2 (Flash)
Last Updated: 2025-02-10

## Overview
This repository contains complete technical documentation and reverse engineering analysis of RoboEvony, originally designed for Evony: The King of Return (TKR) and adapted for Evony Age II.
