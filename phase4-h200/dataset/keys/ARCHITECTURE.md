## Integration Points

### Svony ↔ Flash Toolkit

```python
# In Svony codebase:

from flash_toolkit import sol_reader, swf_analyzer

# Read account data
accounts = sol_reader.find_all_evony_sols()

# Analyze game client
client_info = swf_analyzer.get_api_endpoints("EvonyClient.swf")

# Launch bot with specific account
sol_reader.set_active_account(account_id)
bot_launcher.start("roboevony.exe")
```

### Recommended Integration

1. **rust-flash-lso** for SOL parsing (fast, reliable)
2. **Py3AMF** for Python scripting
3. **FFDec CLI** for batch SWF operations
4. **SQLite** for account database
5. **WebSocket** for bot communication
