Design and create a comprehensive automated Windows installer generator system that can convert GitHub repositories into proper Windows installers. The system should meet these specific requirements:

**Core Functionality:**
- Automatically analyze any GitHub repository and generate a Windows installer (.msi or .exe)
- Target compatibility: Support 80%+ of GitHub repositories across all major programming languages
- Full automation: Minimal to zero user intervention required

**Technical Requirements:**
- **Environment Detection & Setup**: Automatically detect and configure appropriate development environments (Conda, UV, Poetry, pip, npm, Maven, etc.)
- **Dependency Management**: Scan, download, and bundle all required dependencies
- **Cross-Platform Support**: Utilize WSL2, Docker containers, and native Windows tools as needed
- **System Compatibility**: Support Windows 7, 10, and 11
- **Build System Integration**: Handle various build systems (Make, CMake, Gradle, npm scripts, etc.)

**Architecture Components:**
1. **Repository Analyzer**: Parse repo structure, detect language/framework, identify build requirements
2. **Environment Manager**: Set up isolated build environments using appropriate tools
3. **Dependency Resolver**: Handle package managers and external dependencies
4. **Build Orchestrator**: Execute build processes in correct sequence
5. **Installer Generator**: Package everything into Windows installer format
6. **Validation System**: Test installers before distribution

**Integration Requirements:**
- GitHub API integration for repository access
- Cloud AI provider integration for complex conversion decisions
- Windsurf IDE compatibility for development assistance
- Docker/WSL2 containerization for isolated builds

**Deliverables:**
- Detailed technical architecture document
- Implementation roadmap with milestones
- Proof-of-concept for 15-35 different repository types (top 20-25 most used)
- Scalability plan for handling high-volume conversions
- Error handling and fallback strategies

Provide a realistic action plan with specific technologies, tools, and implementation steps needed to build this system.
