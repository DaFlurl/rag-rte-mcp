## Tips for Best Results

### DALL-E 3 Tips:
- Add "professional", "clean", "high quality" for polished results
- Specify "no text" if you want to add text yourself later
- Use "isolated on black/white background" for icons
- Request specific aspect ratios: "16:9", "1:1", "square"

### Midjourney Tips:
- Add `--v 6` for latest version
- Use `--style raw` for cleaner, less stylized results
- Add `--ar 16:9` for banners, `--ar 1:1` for logos
- Include `--no text, letters, words` to avoid AI-generated text

### Stable Diffusion Tips:
- Use negative prompts to avoid unwanted elements
- Higher CFG scale (7-12) for more prompt adherence
- Add "vector art" or "flat design" for icon-style outputs
