V)~SETTINGS_Glossary~

[ALLSETTINGS] - This Heading is For Account Controls: Things that effect both goals and scripts.

set useFacebook OFF
~useFacebook (ON/OFF) tells the bot what to build in what priority, without fb it builds res first.
set fieldType s
~fieldType ( f s q i ) controls what fields your alts will make. Adjust this to the highest priced res.

[ACCOUNTSETTINGS] - This Heading is for script only Controls, City location, Account layout.

set govAccount "Govenor"
~govAccount (Name) is who u will vote for daily.
set mainAccount "YourStrongestAcc"
~mainAccount (Name) is who u will mail for starting quest.
set manualLocation OFF
~manualLocation (ON/OFF) gives you control over exact city locations.
set centerAround14 OFF
~centerAround14 (ON/OFF) gives you the option to build cities around the closest 14.
set cityGrid ON
~cityGrid (ON/OFF) Spaces all cities out evenly from each other. (Recommended ON)
set iWantCastle Inactive
~iWantCastle (ON/OFF) //Option inactivated.
set homeState "Tus"
~homeState (first 3 digits/first 2 initials of state name) Tells bot what state to random to when starting.
set manualCoord 0,0
~manualCoord (xxx,yyy) sets the coord for manualLocation to position your cities.
set gridDistance 12
~gridDistance (miles) Sets spacing for cityGrid.
set flagType 1
~flagType (flag) Tells the bot what flag u want it to have in when starting.
set startUpCycle 3
~startUpCycle (seconds) sets the amount of sleep between tasks when starting an account, important to adjust.

[GOALSETTINGS] - This Heading is for goal only Controls.

set rebuildCity OFF
~rebuildCity (ON/OFF) controls if Unneeded builds get removed in all cities.
set finishKeyBuilds ON
~finishKeyBuilds (ON/OFF) controls if Mich scripts get used as they are farmed on important buildings.
set autoUseFaceBook ON
~autoUseFaceBook (ON/OFF) controls if your new cities will autouseitems for visit packs.
set controlZeroFood ON
~controlZeroFood (ON/OFF) controls if this account uses zerofood in its main city.
set dailyReset OFF
~dailyReset (ON/OFF) controls if this account will schedulepolicy to turn off for 1 hr a day.
set altType "Archer"
~altType (Archer, Ballista, Scout) Sets what final troop type this alt will make after done promotion.
