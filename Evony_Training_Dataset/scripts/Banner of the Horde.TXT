You must also append the additionally required parameters telling it to use
 the desired items. There is one for war ensign and one for 
banner of the horde.

Ex

qdeploy attack xxx,yyy Julie s:5k,w:10k,a:200k,sw:1,p:1 g:0 0:0:0 false true


The false means do not use an ensign, and the true means to use a banner.
 Notice you must include something for the resource and 
camp time parameters as well since they appear before the item parameters.
 You can always find out more about a 
given script command by using the info command.

Ex

info qdeploy
